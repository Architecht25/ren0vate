# Palette de couleurs ren0vate

## Palette principale - Harmonie naturelle & professionnelle

```css
/* Variables CSS - Palette ren0vate */

--slate-blue: #334155;    /* Bleu ardoise - couleur principale professionnelle */
--terracotta: #D97706;    /* Terracotta - accent chaleureux (chantier/matériaux) */
--sage-green: #84A98C;    /* Vert sauge - écologie et nature */
--sand-beige: #E6DDD3;    /* Beige sable - arrière-plans doux */
--charcoal: #2F2F2F;      /* Charbon - textes et éléments sombres */
```

## Aperçu visuel

| Couleur | Code | Usage |
|---------|------|-------|
| 🟦 Bleu Ardoise | `#334155` | Navigation, en-têtes, boutons primaires |
| 🟧 Terracotta | `#D97706` | CTA, badges, éléments importants |
| 🟩 Vert Sauge | `#84A98C` | Succès, labels écologiques, primes validées |
| ⬜ Beige Sable | `#E6DDD3` | Backgrounds, cartes, sections |
| ⬛ Charbon | `#2F2F2F` | Texte principal, icônes |

## Cohérence de la palette

Cette palette est cohérente car :
- **Tons naturels** : toutes les couleurs évoquent des matériaux de construction (ardoise, terre cuite, bois, sable)
- **Température équilibrée** : mélange harmonieux de couleurs froides (bleu, vert) et chaudes (terracotta, beige)
- **Contraste maîtrisé** : bon équilibre entre couleurs foncées et claires
- **Professionnelle mais chaleureuse** : évite le côté trop corporate tout en restant sérieuse
